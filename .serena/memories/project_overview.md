# go-echo-boilerplate — Project Overview

## Purpose
A production-grade Go REST API boilerplate using the Echo framework. It is **not** a code-generation scaffold; it is a working, runnable backend service with real domains (users, tokens) that developers fork and extend.

## Tech Stack
- **Language**: Go 1.24
- **HTTP Framework**: Echo v4 (`github.com/labstack/echo/v4`)
- **Database**: PostgreSQL via GORM (`gorm.io/gorm`, `gorm.io/driver/postgres`)
- **Auth**: JWT (`github.com/golang-jwt/jwt/v5`), API key middleware, Google OAuth2
- **Logging**: Uber Zap (`go.uber.org/zap`) with a custom "wide-event" pattern (one structured log line per request)
- **Config**: Viper (`github.com/spf13/viper`), environment-specific YAML files in `config/`
- **Validation**: `github.com/go-playground/validator/v10` + `github.com/hashicorp/go-multierror`
- **Migrations**: Goose (`goose -dir migration/db/postgre postgres ...`)
- **API Docs**: Swagger via swag + Scalar UI served at `/api-docs`
- **Hot Reload**: Air (`.air.toml`)
- **Containerization**: Docker Compose (`docker-compose.yml`)

## Architecture
Clean architecture layers:
```
cmd/http/              — entrypoint (main.go)
internal/
  config/              — config model + loader
  core/                — setup.go (wire everything) and teardown.go (graceful shutdown)
  models/              — domain structs, request/response types
  deliveries/http/     — Echo handlers, router, middleware
    middleware/        — cors, logger, jwt, api_key, recover, default
    api/v1/            — versioned handlers (e.g. user_v1_handler.go)
    health_check/      — /health endpoint
  service/             — business logic (interfaces + implementations)
  repository/          — data access (Postgre sub-package)
  pkg/                 — internal utility packages:
    database/          — DB connection (postgre_database.go)
    errorc/            — custom error type with safe public/internal split
    logger/            — wide-event logging context helpers
    response/          — HTTP response helpers (response.Error, response.ErrorValidation)
    stringc/           — string utilities (SnakeCase, TrimAndUpperCase, etc.)
    boolc/             — bool utilities
    numberc/           — number utilities
    jwtc/              — JWT helpers
    validator/         — hash verification
    generator/         — account number, token, hash generators
    formatter/         — phone number formatting
    graceful/          — graceful shutdown helpers
    openauth/          — Google OAuth2 helpers
migration/db/postgre/  — SQL migration files (Goose)
docs/                  — Swagger JSON/YAML (auto-generated by swag)
config/                — config.local.yaml, config.dev.yaml, etc.
```
